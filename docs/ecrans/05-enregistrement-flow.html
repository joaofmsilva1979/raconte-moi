Résumé du flux :
• Flux A (standard) — Appui long micro → transcription live → confirmation → ✓ sauvegardé. 3 interactions.
• Flux B (badge d'abord) — Tap badge → choisir repas → appui long micro → transcription → ✓ sauvegardé. 4 interactions, zéro ambiguïté.
• Le texte transcrit est toujours modifiable à la main avant de sauvegarder.
• Heure & jour sont capturés automatiquement au moment de l'enregistrement.
