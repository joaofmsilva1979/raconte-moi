C — Ultra-minimal (ma reco)

Un seul écran intelligent. Le bouton est ÉNORME, impossible de rater. Les 2-3 derniers repas apparaissent en dessous. Le journal complet se déploie par glissement vers le haut. Bleu/indigo, moderne, épuré.

✅ 0 navigation = 0 confusion
✅ Micro toujours visible
✅ Journal accessible sans quitter l'écran
Note : Les trois approches partagent le même moteur (vocal → transcription → catégorie automatique par heure → stockage local). La direction choisie influence uniquement l'expérience d'ouverture de l'app.
