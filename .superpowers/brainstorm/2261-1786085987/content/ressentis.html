Ressentis — Intégration dans le design

Un ressenti peut être ajouté à n'importe quel moment, indépendamment d'un repas. Il apparaît dans le journal chronologiquement, visuellement distinct des repas.

Comment déclencher un ressenti ?
💜 Bouton dédié sous le micro Recommandé
Un petit bouton "💜 Ressenti" sous le bouton micro. Toujours visible, toujours accessible. Ouvre une sheet rapide avec les catégories.
✅ Clair et distinct
✅ Pas de confusion avec l'enregistrement repas
✅ Accessible depuis l'écran principal ET le journal
⚠️ Ajoute un élément visuel à l'écran principal
⚡ Tap court sur le micro
Tap court = ressenti, appui long = repas. Deux comportements pour un même bouton.
✅ Interface épurée, 1 seul bouton
⚠️ Discoverability faible — elle ne saura pas
⚠️ Risque de confusion tap/appui long
🔼 Bouton dans le journal uniquement
Le ressenti n'est ajoutée que depuis le journal (glissement ↑). Pas accessible depuis l'écran principal.
✅ Écran principal intact
⚠️ Friction : il faut glisser ↑ d'abord
⚠️ Un ressenti peut arriver quand elle n'a pas le temps

Mise à jour du modèle de données
Nouvelle table : ressentis
id             INTEGER PRIMARY KEY
recorded_at    DATETIME NOT NULL    — heure exacte
category       TEXT NOT NULL      — bloating|nausea|pain|fatigue|good|other
sub_category   TEXT             — belly|head|other (si pain)
note           TEXT             — note vocale transcrite (optionnel)
entry_id       INTEGER          — FK → entries.id (repas précédent, auto-lié)
delay_minutes  INTEGER          — calculé auto : temps depuis le repas précédent
Ce qui est automatique :
• Le lien avec le repas précédent est calculé automatiquement (on cherche la dernière entrée entries avant le ressenti)
• Le délai en minutes est stocké pour permettre des analyses futures ("tu as souvent mal au ventre ~40min après le déjeuner")
• La note vocale suit le même pipeline : transcript brut → Apple Intelligence → texte propre

Catégories proposées : 😮‍💨 Ballonnement · 🤢 Nausée · 😣 Douleur · 😴 Fatigue · 😊 Je me sens bien · ✏️ Autre (vocal)

Couleur : violet/prune pour distinguer visuellement des repas (corail) dans toute l'app.
